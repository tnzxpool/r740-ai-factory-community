# Model licensing and distribution

No model weights are distributed with this repository.

Each optional model manifest must record the upstream repository, immutable
revision, artifact name, size, SHA-256, runtime requirements and upstream
license. A model stays disabled until those fields are complete and the
operator explicitly accepts its license.

The project LGPL license does not replace model licenses. OpenRAIL and other
restricted model licenses remain independent. Unverified derivative models,
including uncensored variants, must not be offered for automatic download.
