# Third-party notices

This initial packaging skeleton uses only the Python standard library at
runtime. Docker, systemd, NVIDIA drivers/toolkit and any OpenAI-compatible
inference backend are external prerequisites and are not redistributed.

The complete R740 AI Factory application will add separately installed Python
dependencies. Their versions, licenses and source locations must be generated
from the final lock files before the first public release. No dependency is
relicensed as LGPL by this project.
